# CODEWAVE Academy

가상의 IT 전문 교육기관을 위한 React + Vite 반응형 랜딩 페이지입니다.
다크 네이비와 블루, 코드에서 가능성으로 이어지는 궤도 그래픽으로 브랜드를 표현했습니다.

## 실행

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
npm run lint
```

## 주요 기능

- Header / Hero / 교육과정 / 교육 특징 / 학습 여정 / 문의 CTA / Footer
- **풀스택 웹 개발자 과정**, **AI Agent 개발자 과정**과 펼쳐 보는 커리큘럼
- 과정 카드에서 선택한 과정이 상담 체험으로 연결되며, 첫 주 학습 계획을 표시
- 실제 상담 접수나 개인정보 전송 없이 동작하는 데모
- 모바일 메뉴, 본문 바로가기, 키보드 포커스 표시, 폼 레이블, 결과 알림, 모션 감소 설정 지원
- 외부 이미지·폰트 요청 없이 CSS로 표현한 브랜드 그래픽

## 바이브 코딩 기록

### 1. 요구사항

두 교육과정을 명확히 소개하고, 다크 네이비·블루의 반응형 홍보 페이지를 구현한다.
장식성 버튼 대신 유효한 앵커와 동작하는 상담 체험을 제공한다.

### 2. AI 구현

기존 main 브랜치와 미커밋 Vite 파일을 확인하고 원본을 별도 백업했다.
React 컴포넌트와 과정 데이터, CSS 반응형 레이아웃, 과정별 학습 계획을 구현했다.
가상의 기관이므로 실제 모집·취업 성과를 주장하지 않고 데모임을 명시했다.

### 3. 브라우저 검증 (2026-11-06)

- 모바일 382px: Hero·과정 카드·CTA 표시, 가로 넘침 없음
- 모바일 메뉴 열기 → 교육과정 앵커 이동 → 메뉴 닫힘 확인
- AI Agent 과정 커리큘럼 펼침 → 4개 모듈 표시 확인
- 과정에서 상담 체험으로 이동 → AI 과정 자동 선택 → Python 기반 첫 주 계획 표시 확인
- 데스크톱 1440px: Header, 2열 Hero, 가로 기술 목록 표시 및 가로 넘침 없음
- 브라우저 콘솔 오류 없음
- `npm run build`, `npm run lint` 통과

### 4. 피드백과 다음 반복

모바일 검증에서 내용 잘림이나 가로 스크롤이 발견되지 않았고, 과정 선택도 정상 연결됐다.
실제 상담 연동이 없는 과제이므로 CTA를 개인정보 없는 학습 계획 체험으로 구체화했다.
다음 사용자 피드백에서는 문구·여백·과정 상세 수준을 확인하고, 변경 후 같은 동작을 재검증한다.
